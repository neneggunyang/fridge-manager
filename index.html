이 브라우저에 저장된 식재료, 냉장고 선반 설정, 요리·식단 메모를 JSON 파일로 백업할 수 있어요. 다른 기기나 브라우저로 옮길 때도 이 파일을 사용하세요.

복원하면 현재 브라우저의 데이터가 백업 파일 내용으로 교체됩니다. 복원 전 현재 데이터도 별도 백업 파일로 내려받도록 했어요.

☁️ 클라우드 저장

로그인한 계정에 냉장고 데이터를 저장하고, 실제 저장 상태와 마지막 저장 시각을 확인할 수 있어요. 자동 동기화 외에 필요할 때 직접 저장할 수도 있어요.

☁️

클라우드 연결 상태

로그인하면 냉장고 데이터를 클라우드에 저장할 수 있어요.

기존 냉장고 데이터를 클라우드로 옮길까요?

이 브라우저에 기존 냉장고 데이터가 있어요. 먼저 백업 파일을 내려받아 안전한 곳에 보관한 다음, 현재 데이터를 이 계정의 클라우드에 저장할게요. 백업을 확인하기 전에는 클라우드 저장을 진행하지 않아요.

💾 1. 기존 데이터 백업

식재료, 선반 설정, 요리·식단 메모를 JSON 파일로 내려받아요. 다운로드가 끝났는지 확인하고 파일을 보관해주세요.

☁️ 2. 클라우드에 저장

백업 파일을 확인한 뒤 아래 버튼을 누르면 현재 브라우저의 데이터를 계정에 저장해요. 기존 클라우드 데이터가 없을 때만 진행돼요.

백업 파일을 다운로드하고 보관한 뒤 2단계를 눌러주세요.

기존 냉장고 데이터를 어떻게 가져올까요?

이 계정에는 이미 클라우드 데이터가 있고, 현재 브라우저에도 별도로 저장된 데이터가 있어요. 두 데이터를 자동으로 합치지는 않으므로 사용할 쪽을 선택해주세요. 선택 후에는 앱 화면 맨 아래의 ‘🧳 데이터 백업 · 복원 · 클라우드 저장’ 탭에서 클라우드 저장 상태를 확인하거나 현재 데이터를 직접 저장할 수 있어요.

☁️ 클라우드 데이터를 사용하기

이 계정에 저장된 식재료·선반 설정·요리 메모를 현재 브라우저로 불러와요. 현재 브라우저 데이터는 앱 화면에서 교체되지만, 선택 전에 별도 백업 파일로 내려받아요. 다른 기기에서 쓰던 데이터를 이어갈 때 선택하세요.

💻 현재 브라우저 데이터를 사용하기

지금 이 브라우저에 보이는 식재료·선반 설정·요리 메모를 클라우드에 저장해 이 계정의 기존 클라우드 데이터를 교체해요. 기존 클라우드 데이터는 선택 전에 별도 백업 파일로 내려받아요. 현재 브라우저 데이터가 최신일 때 선택하세요.

두 선택 모두 먼저 백업 파일을 다운로드해요. 다운로드가 완료되면 파일을 보관해두세요. 데이터가 어느 쪽이 최신인지 모르겠다면 선택을 미루고 백업부터 확인하는 것이 안전해요.
